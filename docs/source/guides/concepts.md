# Core Concepts

TinyToT reasons. Howl speaks. Ear hears. Eye stores a picture. NanoToT
only copies and forgets. Forgetting is the point of a child.

| Verb | Whose tree | Media | Stage |
|---|---|---|---|
| `tinytot-clone` | the *server* install | n/a | n/a |
| `nanotot pack` | an organism `/tiny/` | kept | kept |
| `nanotot child` | an organism `/tiny/` | dropped | baby |
